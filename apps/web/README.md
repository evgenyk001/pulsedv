# PULSE.DV web funnel

Имиджевый одностраничный сайт PULSE.DV.

Сайт не является каталогом, калькулятором или отдельным сервисом. Его единственная задача — красиво презентовать мобильное приложение PULSE.DV и привести пользователя к главному действию: открыть приложение.

## Структура
- Hero с продуктовым визуалом.
- Позиционирование PULSE.DV.
- Большая демонстрация интерфейса.
- Краткое объяснение возможностей приложения.
- Имиджевый storytelling-блок.
- Блок доверия к команде PULSE.DV.
- Финальная презентация приложения и CTA.

## Принцип
Минимум текста, крупные визуалы, премиальная типографика, лёгкая motion-глубина и один главный CTA.
