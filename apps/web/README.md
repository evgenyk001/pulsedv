# PULSE.DV funnel — v1

Одностраничная воронка PULSE.DV. Это не каталог и не веб-версия Mini App.

## Что уже есть
- desktop/mobile hero в стиле согласованного макета;
- два продуктовых mockup-телефона;
- лёгкий parallax и reduced-motion fallback;
- CTA с короткой лид-воронкой;
- шаги: город → бюджет → первоначальный взнос → способ покупки → комнаты → контакт;
- тестовое сохранение лида в localStorage.

## Что подключим следующим этапом
- реальный Telegram Mini App URL + настоящий QR;
- PULSE Control Center endpoint для сохранения лидов;
- аналитика событий и UTM;
- реальные скриншоты текущего PULSE после переноса из Floot;
- финальные соцсети/юридические ссылки/домен.
