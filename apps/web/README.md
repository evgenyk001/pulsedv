# PULSE.DV — одностраничный сайт-воронка

Эта ветка — только сайт-воронка. Никакого каталога, Mini App-логики, CRM или Control Center внутри сайта.

## Сценарий
1. Пользователь видит один сильный экран.
2. Нажимает «Подобрать квартиру».
3. Коротко отвечает: город → бюджет → способ покупки → контакт.
4. Пока лид сохраняется локально для проверки UX.
5. Позже подключим отправку контакта в рабочую систему агентства.

Визуал справа — только статичная рекламная графика.
