# PULSE.DV web funnel

Одностраничная продуктовая воронка PULSE.DV.

## Логика страницы
Страница построена как последовательная история продукта, а не как веб-каталог:
1. Главный экран и переход в PULSE.
2. Быстрый выбор задачи.
3. Поиск новостроек.
4. Сравнение вариантов.
5. Предварительный расчёт ипотеки.
6. PULSE Select.
7. Помощь специалиста.
8. Финальный переход в приложение.

Каталог, реальные карточки ЖК и рабочая CRM остаются частью Mini App / Control Center.
