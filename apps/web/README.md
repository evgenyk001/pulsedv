# PULSE.DV website funnel

Текущая задача этой ветки — отдельный одностраничный маркетинговый сайт-воронка PULSE.DV.

## Зафиксированная концепция
- один сильный первый экран, без каталога на сайте;
- минимум текста;
- светлый фирменный стиль PULSE.DV;
- статичный product visual справа;
- две цели: открыть PULSE или пройти короткую лид-воронку;
- mobile-first адаптация;
- Mini App, CRM и Control Center будут развиваться отдельно после переноса текущего проекта из Floot.

## Lead flow v1
Город → бюджет → способ покупки → контакт.

Пока тестовый лид сохраняется в localStorage. После подключения backend он будет отправляться в PULSE Control Center.
