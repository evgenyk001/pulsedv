# Защита партнёрского кабинета

В профиле рядом с «Уведомлениями» находится «Защита партнёрского кабинета».
Защита включается добровольно в мобильном Telegram, если телефон поддерживает биометрию.
Каталог, подбор и избранное остаются доступны без неё.

При включении Telegram запрашивает доступ к биометрии и право бота написать пользователю
(оно необходимо для восстановления). Сервер выпускает случайный секрет, Telegram
сохраняет его в биометрическом хранилище. Только после успешного чтения через нативную
проверку сервер активирует защиту. Сервер хранит SHA-256 секрета и идентификатора устройства;
изображения лица и отпечатки не собираются.

Одна активная привязка устройства на пользователя. Вход с другого устройства требует
восстановления через код в личном чате бота. Все API кабинета защищены сервером независимо
от вкладки и сессии. Доступ выдаётся на 10 минут и привязан к пользователю, сессии и редакции
привязки; интерфейс блокируется через 9 минут, при уходе из раздела и сворачивании приложения.
Клиент хранит временный доступ только в памяти и очищает кэш клиентов при блокировке.
Изменение реквизитов и отключение защиты требуют подтверждения не старше минуты.

Восстановление через Telegram отключает привязку и отзывает все временные доступы.
Код действует 5 минут, допускает 5 попыток и принимается только в запросившей его сессии.
Повторный код доступен через минуту, прежний становится недействительным. Неактуальные коды
не доставляются; доставленные коды удаляются из payload очереди. После восстановления
защиту можно включить заново. Сброс не требует подписки на рекламные анонсы.

Для запуска: применить миграцию 025, запустить API и worker, подключить BOT_TOKEN и Telegram
Mini App. На GitHub Pages настройка отображается, но не симулирует успешное включение.
Реальный системный Face ID необходимо проверить на физических iPhone/Android перед запуском.
Автотесты проверяют адаптер Telegram, серверную проверку и браузерные сценарии с имитацией SDK.

Это дополнительная проверка доступа: токен Telegram является bearer-секретом, не аппаратной
аттестацией и не доказательством личности. Она не заменяет проверку Telegram initData,
антифрод, защиту от XSS или ручную проверку получателя выплаты.

В интерфейсе используется PULSEDV.RU; служебные ключи браузерного хранения и существующие
версии оферт сохранены для совместимости с избранным, данными и принятыми документами.
