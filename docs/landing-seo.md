# SEO лендинга PULSE.DV

По указанию владельца внешний вид, видимые тексты, кнопки, ссылки, изображения и структура лендинга сохранены. Дополнительные страницы не создаются. Изменения относятся только к технической подготовке поиска на будущем `https://pulsedv.ru/`.

## Что настроено

- Title и description под новостройки и ипотеку Приморья с упоминанием Владивостока, Артёма и Уссурийска.
- Канонический адрес `https://pulsedv.ru/`, Open Graph, социальное превью и JSON-LD Organization / WebSite / WebPage. Только достоверное название, территория работы и известная публичная ссылка Instagram; нет вымышленных офисов, отзывов, рейтингов и ставок.
- Производственный `sitemap.xml` содержит только главную. Корневой `robots.txt` указывает на карту и исключает служебные маршруты. HTML приложений содержит noindex, Caddy добавляет X-Robots-Tag на служебных маршрутах. Это не замена авторизации.
- `npm run seo:build` обновляет только head лендинга и служебные файлы. Выполняется при общей сборке и сборке VPS-образа. `npm run seo:check` проверяет, что весь body сохранён, JSON-LD корректен и режимы production/preview переключаются воспроизводимо.
- На GitHub Pages при публикации используется `node scripts/build-seo.mjs --preview`: лендинг получает noindex, карта удаляется и ссылка Sitemap не добавляется в robots.txt. GitHub Pages проекта не управляет корневым `evgenyk001.github.io/robots.txt`; от индексации превью защищает именно meta noindex. Производственная сборка возвращает index и карту домена. Не следует вручную привязывать production-домен к этому preview-процессу без изменения режима сборки.

## После подключения домена

1. Направить `pulsedv.ru` на сервер и включить HTTPS. В VPS указать `SITE_DOMAIN=pulsedv.ru`. При проверке 20 октября 2026 домен не удалось открыть; работа production-домена пока не подтверждена.
2. Проверить ответы 200 для главной, `/robots.txt` и `/sitemap.xml`, отсутствие noindex на главной и канонический адрес. Если используется www, отдельно настроить DNS/TLS и постоянный редирект на домен без www.
3. Добавить домен в Яндекс Вебмастер и Google Search Console. Подтвердить права DNS-записью, которую выдаст соответствующий сервис; выдуманные проверочные токены не используются.
4. Передать `https://pulsedv.ru/sitemap.xml` и отправить главную на переобход. Указать фактическую территорию работы в Яндекс Вебмастере. Не добавлять GitHub-превью как основной сайт.
5. Подтвердить реальную карточку PULSE.DV в Яндекс Бизнесе: рабочий телефон, адрес приёма, часы работы и ссылка на домен. Не создавать вымышленные филиалы. Публичные реквизиты и контакты на лендинге добавлять только после отдельного согласования изменения его содержания.
6. После запуска API проверить переходы в PULSE Control; общая статистика не работает в статической браузерной копии. Метрику подключать с настоящим номером счётчика и согласованными настройками обработки данных.

Нужны доступ к DNS, подтверждение Вебмастера/Search Console и данные реальной карточки организации. Настройки в этих внешних кабинетах не выполнены одной публикацией исходного кода.

## Ограничения

Техническое SEO помогает поисковику обнаружить и понять страницу, но не гарантирует индексирование, срок появления и первое место. На одностраничном лендинге с фиксированным содержанием возможности продвижения по всем широким запросам ограничены. Дополнительные тексты или страницы без согласования владельца не добавляются. Результат оценивается по показам, запросам, кликам и обращениям в Вебмастере, Search Console и серверной аналитике после запуска.
