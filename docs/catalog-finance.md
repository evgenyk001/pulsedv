# Актуальность каталога и комиссии

В PULSE Control редактор ЖК хранит источник цены и условий, имя ответственного,
время проверки и дату следующей проверки. Кнопка «Данные проверены сегодня»
доступна после заполнения источника и ответственного; по умолчанию следующая
проверка через семь дней. В API отметка сохраняется вместе с карточкой.
В демонстрации изменения сохраняются автоматически в текущем браузере.

Фильтр «Требуют проверки» показывает непроверенные объекты, объекты без срока
повторной проверки и объекты с наступившим сроком, включая сегодняшний день.
Даты считаются по Владивостоку. Источник и ответственный не передаются через
публичный каталог. Импорт без полей актуальности сохраняет существующие отметки.
Редактирование по устаревшей версии отклоняется, права редактора каталога прежние.
Это рабочая очередь для сотрудника, без автоматической рассылки напоминаний.

В карточке клиента есть комиссия агентству, выплата агенту, ожидаемая дата
поступления, дата полного поступления и дата полной выплаты агенту. Суммы —
целые рубли. Фактические даты не могут быть в будущем; выплата не может превышать
комиссию. Частичные платежи пока не поддерживаются.

Аналитика отдельно показывает ожидаемые комиссии без факта поступления,
полученные комиссии и выплаты агентам за выбранный период, включая обе границы.
Поступление и выплата относятся к своим фактическим датам. Их разность — движение
денег до налогов, рекламы и прочих расходов, а не чистая прибыль. На сервере
итоги считаются по всем доступным заявкам, независимо от пагинации CRM.
Менеджер получает итоги только назначенных ему клиентов.

Перед запуском новой версии API выполните обычный шаг миграции: миграция
`012_catalog_freshness_finance.sql` добавляет два JSONB-поля без удаления данных.
После переноса на VPS нужно проверить эти сценарии на рабочей базе и включить
резервное копирование. GitHub Pages остаётся демонстрацией с локальными данными.

Mini App загружает главный экран сразу, остальные экраны отдельными модулями при
переходе. Навигация сохраняется во время загрузки; при ошибке модуля предлагается
обновить приложение. При публикации нужны все файлы новой сборки, включая chunks.
