# Отправка ЖК без розыгрыша

Этот релиз основан на каталоге до розыгрыша. Он не включает баннер, страницу, настройки Control, таблицы, уведомления или изображения конкурса. Разработка розыгрыша сохранена отдельно в ветке `feat/new-year-giveaway` и не применяется этим установщиком.

«Поделиться» готовит сообщение с названием ЖК и кнопкой «Открыть ЖК в PULSE» в клиентах Telegram с поддержкой shareMessage. В старых клиентах и при недоступности подготовки используется Telegram-ссылка. Получателей выбирает пользователь; API сам сообщение не отправляет.

Ссылка содержит только имя бота и закодированный ID опубликованного объекта. Base64url — кодировка, а не шифрование. В ссылке нет ключей, токена бота, авторизации или личных данных отправителя. Параметр управляет только навигацией, не даёт доступ к CRM и чужим данным. Приложение сохраняет обязательный вход по действующей конфигурации; сервер проверяет сессию и телефон. Подготовка сообщений доступна только для опубликованных ЖК; Telegram ID отправителя берётся из его серверной сессии.

Эти проверки относятся к изменённому механизму и не являются гарантией отсутствия уязвимостей во всём проекте. Старые отправленные браузерные ссылки не меняются.

Для установки: `bash deploy/update-property-share.sh <проверенный SHA>`. Установщик сохраняет локальные образы отката, проверяет восстановление дампа в отдельную БД и целостность медиа, собирает сервисы и сверяет выполняемый код/HTTPS. Новых миграций для отправки ЖК нет. Установка поверх уже установленной ветки розыгрыша намеренно остановится на проверке предка; этот сценарий здесь не предусмотрен.
