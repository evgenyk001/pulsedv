## Проверки и границы

Локально: проверки TypeScript, backend-регрессии с PGlite, production-сборка, аудит зависимостей, синтаксис эксплуатационных скриптов. Полный браузерный прогон и PostgreSQL — в GitHub Actions. Установка Chromium в рабочей среде блокировалась повреждённой загрузкой, поэтому локальный browser pass не заявляется.

VPS пока отсутствует: реальный restore drill, доставка Telegram, работоспособность мониторинга и резервного хранилища проверяются после настройки инфраструктуры. GitHub Pages остаётся демонстрацией без рабочего backend.

Дальнейшие оптимизации из раздела «после основных исправлений» аудита — разделение bundle, кластеризация карты и отдельный нагрузочный прогон большого каталога — не являются частью этой корректирующей миграции. Внешний вид приложения сохраняется.
