# Страница ЖК и расчёт по объекту

Страница использует полный опубликованный объект из Catalog Engine: фото, порядок,
подписи, точную стартовую цену, планировки, характеристики, адрес и документы.
Наличие конкретных квартир не выводится из количества планировок.

## Галерея

Обложка первая, затем до 100 фотографий из Control по sortOrder. Повторные URL
показываются один раз. Нажатие открывает полноэкранную галерею с фото целиком,
горизонтальным листанием, стрелками, миниатюрами и подписями. Закрытие возвращает
выбранный кадр в галерею страницы, сохраняет прокрутку и фокус. Ошибка изображения
не блокирует просмотр остальных. Загружаются текущий и соседние полноэкранные кадры.

Control позволяет менять порядок и подписи; на VPS сохранён многократный upload
JPG/PNG/WebP. В демонстрации можно редактировать ссылки. Сервер ограничивает галерею
100 фотографиями также при upload; отклонённый файл удаляется. Обложка отдельная.

## Цены и ипотека

Поля редактора ЖК и планировок принимают целые рубли. Внутренний контракт API/CSV
сохраняет миллионы рублей. Миграция 015 расширяет numeric(14,2) до numeric(18,6),
поэтому 7.543219 млн сохраняются как 7 543 219 ₽. Существующие значения сохраняются;
утраченную старым округлением точность нельзя восстановить без исходного прайса.
CSV по-прежнему принимает цены в миллионах: шаблоны и существующие импорты совместимы.

Ссылка из ЖК/планировки содержит property, price, from=property, down=min и при
необходимости floorplan. Калькулятор начинает с новостройки и минимального взноса
выбранной программы; старый взнос/тип недвижимости/флаг большой площади не переносится.
Программа, срок и семейные настройки сохраняются. Право на программу не подтверждается
самим переходом. Банковские правила этим обновлением не меняются.

После загрузки карточки цена сверяется с текущими данными каталога. При редактировании
стоимости/взноса пользователем поздний ответ не перезаписывает ввод. Известная цена
объекта не обрезается прежним диапазоном ползунка 3–45 млн. Удалённая планировка явно
обозначается; вместо неё используется стартовая цена ЖК. Если объект недоступен,
остаётся ориентировочный расчёт без привязки заявки к недоступной карточке.

Заявка из калькулятора сохраняет ЖК, ID планировки (если есть), комнатность, площадь,
цену, взнос, срок, программу, ставку и платёж. Эти факты доступны в Control; действующие
права доступа и очередь уведомлений владельцу сохранены.

## Проверки и перенос

Серверная регрессия проверяет точность PostgreSQL/API, подписи/порядок фото, привязку
заявки к планировке, ограничения upload и отсутствие оставшегося отклонённого файла.
Браузерные проверки Chromium/WebKit на 320/390/430 px проходят путь галерея → ипотека
→ заявка → Control, изменение данных в CRM и цену за пределами старого диапазона.

На VPS применить миграции перед обновлением API/worker. GitHub Pages остаётся локальной
демонстрацией: файлы с компьютера загружаются в постоянное хранилище в серверном режиме.
