# Living city / experimental direction

Open `city.html` alongside the unchanged `index.html` release. The private review
site serves city.html at its root and preserves the earlier release at previous.html.
This is a visual study; the production landing-only installer does not select it.

The scene uses original PULSE header artwork and existing photographed-style
phone bitmaps, with a new lightweight SVG architectural set, a continuously breathing, layered red thread confined to the phone scene, lighting, contact
shadows, a continuous spring-driven red thread and bounded pointer parallax.
The curve deforms continuously during scene holds, with a travelling highlight;
the phone composition is slightly larger to balance the quieter, more spacious
left column. No new 3D phone model, external font, remote runtime dependency or invented
property is introduced. Five scenes include catalogue, apartment/floorplan,
favourites/mortgage, partnership and giveaway. Images decode before scene exit.
One pair is present at a time; mobile portrait shows one image from that pair.

The left column omits the city eyebrow and uses a stronger headline, shorter
supporting copy, a compact
local Lottie benefit strip and rounded entry buttons with a quieter near-monochrome social header. The handwritten social note and
its runtime script are removed from this concept. PWA remains marked Soon in this study.
Reduced-motion visitors get a still first scene; hidden documents suspend motion.
Escape toggles motion. Mobile has an independent centered grid and no page scroll.

Validation: JavaScript syntax; browser inspection of 1363×936, 390×844,
320×640 and 1366×568 layouts and later automatic scenes. Physical-device frame
rates and production server deployment are not verified in this study.
