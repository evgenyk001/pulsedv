# PULSE.DV

Mini App для подбора недвижимости и PULSE Control для команды продаж.

- [Открыть Mini App](https://evgenyk001.github.io/pulsedv/mini-app/)
- [Открыть демонстрацию Control](https://evgenyk001.github.io/pulsedv/control-center/)

## Два режима

**GitHub Pages** — интерактивная демонстрация. Каталог, избранное и заявки сохраняются только в браузере. Демозаявки не отправляются менеджеру. Control на Pages не содержит серверных данных.

**VPS** — тот же интерфейс с API, PostgreSQL, проверкой Telegram initData, входом сотрудников, разграничением прав, общей базой заявок и очередью уведомлений. Режим включается при сборке через `VITE_PULSE_MODE=api`. Не подключайте публичную демонстрацию Control к рабочей базе без серверной авторизации.

## Разработка

Node.js 22+, npm. Из корня репозитория:

```sh
npm ci
npm run verify
npm run dev
```

Открыть `http://localhost:4173/pulsedv/mini-app/` или `/pulsedv/control-center/`.
`npm test` использует PostgreSQL-совместимый PGlite; с `TEST_DATABASE_URL` запускается на отдельной тестовой базе PostgreSQL. Тесты очищают тестовые данные — рабочую базу указывать нельзя.

CI проверяет типы, API и миграции на PostgreSQL 16, UI на трёх ширинах экрана и сборку Docker. Изменения основной ветки публикуются в GitHub Pages. Для локальных UI-тестов после сборки: `npx playwright install chromium && npx playwright test`.

## Структура

- `apps/mini-app` — публичное приложение; Lottie-навигация, подбор, каталог, ипотека, заявки.
- `apps/control-center` — заявки, задачи, объекты, контент, аналитика, команда.
- `packages/pulse-data` — общий интерфейс данных и адаптер API/деморежима.
- `packages/lead-engine`, `packages/domain` — скоринг и общие правила подбора.
- `backend` — HTTP API, SQL-миграции, worker уведомлений и тесты.
- `deploy`, `compose.yaml` — запуск на VPS, см. [инструкцию](deploy/README.md).
- `dist` — лендинг и результат сборки приложений; лендинг сохранён.
- `apps/floot-mirror` — сохранённый исходный визуальный образец.

## Перед реальным запуском

Нужны домен и VPS, настоящий каталог, токен Telegram-бота, Telegram ID сотрудников, ключ 2GIS для карты и настройка Mini App в BotFather. Рабочий каталог изначально пустой: демонстрационные ЖК не публикуются автоматически. Избранное пока хранится на устройстве; загрузка медиа — через URL. Перед приёмом реальных заявок проверьте резервное копирование, восстановление, тексты согласия и срок хранения данных. Автоматическая очистка по сроку хранения пока не реализована.

## Сохранённый лендинг

Одна адаптивная страница: заголовок, преимущества, рендер телефонов и переход в Telegram.

## Файлы

- `dist/index.html` — семантическая разметка и статичные SVG на случай отключённого JavaScript.
- `dist/style.css` — адаптивный дизайн, локальные шрифты и микроанимации.
- `dist/script.js` — появление элементов, небольшой параллакс и однократный запуск Lottie.
- `dist/assets/benefit-animations.js` — три оригинальные Lottie-анимации PULSE.
- `dist/assets/lottie-light-5.13.0.min.js` — локальный SVG-плеер Lottie, лицензия MIT рядом.
- `dist/assets/pulse-logo-original.jpeg` — предоставленный официальный логотип без изменения исходных пикселей. Фирменный знак и написание показываются через CSS-кадрирование.

Откройте `dist/index.html` для просмотра или загрузите содержимое `dist/` на статический хостинг. Необязательный локальный сервер запускается через `npm run dev` без установки зависимостей.

## Переход в приложение

Все четыре ссылки ведут на **https://t.me/pulsedvbot** и открываются отдельно (`target="_blank"`, `rel="noopener noreferrer"`). Переходы работают без JavaScript. QR содержит тот же адрес. Это ссылка на бота, а не отдельный deep link Mini App.

## Анимации

Каждая из трёх Lottie-иконок запускается один раз при первом появлении в видимой области и остаётся на последнем кадре. `loop: false`, `autoplay: false`; повторного запуска при наведении или прокрутке нет. При `prefers-reduced-motion` видны статичные SVG. Эти же SVG остаются доступными при ошибке плеера.

Декоративный JavaScript не содержит логики приложения, форм, каталога, личного кабинета, базы данных, cookies или localStorage. Внешние скрипты, аналитика и запросы за данными не используются.

## Дизайн и ассеты

Заголовок — Onest, основной текст — Manrope, рукописные подписи — Caveat. Подписи занимают отдельные строки над и под телефонами, без перекрытия изображения. Шрифты размещены локально с лицензиями SIL Open Font License.

Рендер телефонов: 1254×1254, рекламная иллюстрация интерфейса. Сайт остаётся одной страницей без клиентской логики мини-приложения.
